## 브라우저 검증 명령

실행 중인 웹이 필요합니다. 실제 연동 시험에는 API·DB·워커·OCR도 켜져 있어야 합니다. Playwright 설정은 [개발 가이드](DEVELOPMENT.md)를 따릅니다.

| 저장소 루트에서 실행 | 외부 호출 |
| --- | --- |
| `node scripts/check_comparison.cjs` | 없음. HTTP 응답을 합성 데이터로 대체 |
| `node scripts/check_photo.cjs` | 없음. 실제 로컬 OCR |
| `node scripts/check_photo.cjs --search` | 공식 식품 검색 |
| `node scripts/check_web.cjs` | 공식 식품 검색 |
| `node scripts/check_live_comparison.cjs --allow-paid-ai` | 공식 식품 검색 + **유료일 수 있는 외부 AI** |

실제 AI 시험은 명시적 플래그가 필요합니다. 실행당 검색/비교 접수 각 1개로 제한하지만 제공자의 실제 호출 수나 금액 상한을 보장하지 않습니다. 실패 시 자동 재접수하지 않습니다. 반복 실행은 추가 비용이 발생할 수 있습니다.

## 실제 AI 시험 기록

- 직접 생성한 비타민C 합성 광고와 “이 제품은 모든 질병을 치료합니다.”라는 시험 문구 사용.
- 공식 후보 중 기능성 원문이 있는 기록을 시험용으로 선택. 실제 포장과의 제품 동일성을 확인한 것이 아님.
- 최종 실행: 모델 별칭 `claude-sonnet`, 응답 7,675ms, 보고 사용량 1,852토큰, `OVERSTATED` 출력.
- 형식·인용 일치, 새로고침 복원, 동의 해제, 타 세션 404, 삭제, 390px 가로 넘침 없음을 확인.
- 최초 실행은 테스트 완료 대기 로직 문제로 QUEUED 상태에서 실패. 명시적 폴링으로 수정 후 재실행했고 최초 접수의 외부 과금 여부는 확정하지 않음.
- 성공·실패 실행 모두 해당 브라우저 세션의 작업 정리 완료. 외부 제공자의 보관분 삭제는 보장하지 않음.

결과 JSON·화면 캡처·합성 원본은 `private/`에만 보관하며 공개하지 않습니다. 일반 사진/검색 스크립트는 실패 시 생성한 기록이 남을 수 있어 실행 후 확인이 필요합니다.
