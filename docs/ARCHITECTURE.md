# 아키텍처 및 데이터 처리

## 책임 분리

| 구성 요소 | 책임 |
| --- | --- |
| `apps/web` | 사용자 확인·동의·기록 복원 UI, `/backend` 프록시 |
| `apps/api/gyeot/app.py` | 세션, 입력 경계, 작업 접수·조회·취소·삭제 |
| `apps/api/gyeot/db.py` | 영속 작업, 소유권, 중복 요청, 호출 한도, 마이그레이션 |
| `apps/api/gyeot/worker.py` | DB 작업 인수 및 OCR·검색·비교 실행 |
| `apps/api/gyeot/adapters` | 공식 검색·AI 비교·OCR 통신 및 응답 검증 |
| `services/ocr` | Tesseract 한국어·영어 OCR, 임시 처리 파일 정리 |

UI→API는 동일 출처를 사용하며 키는 서버에서만 읽습니다. 워커는 `SKIP LOCKED`로 작업을 인수하고 외부 호출 중 DB 트랜잭션을 유지하지 않습니다. lease token과 만료 검사를 통해 취소·삭제 후 늦은 응답이 결과를 재생성하지 못하게 합니다.

## 작업 수명

`QUEUED → RUNNING → SUCCEEDED / FAILED`, 진행 중 취소 시 `CANCELLED`.

- idempotency key와 payload hash로 같은 요청의 중복 접수를 억제합니다.
- 워커 중단으로 lease가 만료된 작업은 실패로 표시하고 유료 호출을 자동 반복하지 않습니다.
- 결과 처리 성공은 AI 의미 판단의 정확성을 뜻하지 않습니다.
- 제품을 변경하면 이전 제품의 비교 작업을 제거합니다.
- 사진 기록과 검색 기록의 확인 문구는 독립 복사본입니다. 모두 제거하려면 각각 삭제해야 합니다.

## API 개요

| 메서드 / 경로 | 역할 |
| --- | --- |
| `POST /v2/session` | 브라우저 세션 생성·확인 |
| `GET /v2/jobs` · `GET /v2/jobs/{id}` | 소유한 기록 조회 |
| `POST /v2/jobs/ocr` | 동의한 이미지 접수 |
| `GET /v2/jobs/{id}/image` | 세션 전용 이미지 조회 |
| `POST /v2/jobs/{id}/correction` · `/review` | OCR 수정본·확인 제품명/문구 저장 |
| `POST /v2/jobs/search` · `POST /v2/jobs/{id}/selection` | 공식 검색·사용자 제품 선택 |
| `POST /v2/jobs/{id}/comparison` | 별도 동의한 문구 비교 |
| `POST /v2/jobs/{id}/cancel` · `DELETE /v2/jobs/{id}` | 취소·삭제 |

변경 요청은 정확한 Origin과 `X-Gyeot-Request` 헤더가 필요합니다. 작업 접수는 UUID idempotency key를 사용합니다. 이미지에는 별도 동의 헤더가 필요합니다. 세부 계약은 API 스키마와 테스트를 기준으로 합니다.

## 사진과 개인정보

- PNG/JPEG 최대 5MB·1,200만 화소·한 변 8,000px, 최소 32px.
- 파일 형식·손상·다중 프레임을 검사하고 Pillow로 방향 보정 및 메타데이터 없는 PNG 재인코딩을 수행합니다.
- 정리된 이미지를 PostgreSQL `bytea`에 저장합니다. 원본 파일명·업로드 바이트는 DB에 보존하지 않습니다.
- Tesseract `kor+eng`, PSM 6. OCR 컨테이너는 비관리자·읽기 전용 루트·제한된 임시 공간/메모리/CPU로 실행합니다. 네트워크 송신 자체를 차단한 구성은 아닙니다.
- **이미지 내용의 개인정보 자동 마스킹은 없습니다.** 이름·전화번호·대화 등을 사용자가 먼저 가려야 합니다.

| 항목 | 보관 기준 |
| --- | --- |
| 정리된 이미지 | 최대 1시간 |
| 작업·OCR 글자·확인 문구·검색/비교 결과 | 최대 24시간 |
| 브라우저 세션 | 7일 |

만료 즉시 조회를 차단하고 워커 폴링에서 만료 레코드를 정리합니다. 워커가 중지되면 정리는 다음 실행까지 지연됩니다. DB 백업·WAL·디스크의 즉각적인 물리 삭제를 보장하지 않습니다. 쿠키를 잃으면 기록을 복구할 수 없습니다.

## 외부 전송과 결과 해석

- 공식 API: 제품명·품목번호·제조업체 검색 조건만 전송합니다.
- 외부 AI: 사용자가 동의한 광고 문구와 선택 제품의 공식 원문만 전송합니다. 사진은 보내지 않습니다.
- 외부 AI 제공자의 보관·학습·삭제 정책은 별도 확인이 필요합니다. 권한 있는 시험 문구만 사용하세요.
- 모델 출력 형식과 인용 일치는 검사하지만 제품 동일성·의학적 효능·법적 적합성·의미 정확성을 독립 검증하지 않습니다.

공개 배포 전 HTTPS, Secure cookie, 역방향 프록시, CSP, 접근 통제, 모니터링, 백업/복원 및 개인정보 처리 정책을 추가 검토해야 합니다.
