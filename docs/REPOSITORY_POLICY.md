# 저장소 공개 정책

이 저장소는 **실행 가능한 제품 코드와 공개 가능한 개발 문서**만 관리합니다. 연구 원본·운영 데이터·개인 작업 기록을 모으는 저장소가 아닙니다.

## 올릴 것

| 경로 | 내용 |
| --- | --- |
| `apps/web/` | 웹 소스·설정·lockfile·폰트와 라이선스 |
| `apps/api/` | API/워커 소스·SQL·합성 테스트·의존성/lockfile |
| `services/ocr/` | OCR 코드·Dockerfile |
| `scripts/` | 시작·검증·공개 전 검사 스크립트 |
| `docs/` | 공개용 개발·구조·검증 문서와 직접 제작한 소개 이미지 |
| `.github/` | PR 템플릿 |
| 루트 설정·문서 | README, 기여·보안·권리 안내, Compose, 빈 환경 변수 양식, 편집 규칙 |

## 올리지 않을 것

| 종류 | 위치 / 예시 |
| --- | --- |
| 자격 증명 | `.env`, `.env.*` (양식 제외), 개인 키·인증서·서비스 계정 JSON |
| 사용자·연구 데이터 | 광고 원본, 인터뷰, 개인정보, `private/`, `data/`, `uploads/` |
| 실행·검증 부산물 | 로그, PID, 캡처, OCR 결과, 모델 원응답, Playwright 보고서 |
| 로컬 설치·생성물 | `node_modules/`, `.venv/`, `.next/`, 캐시, `next-env.d.ts` |
| 백업·배포 압축물 | DB dump, SQLite 파일, zip, 로컬 임시 파일 |
| 제출·원본 문서 | HWP/HWPX/PDF, 발표·기획 원본. 공개 필요 시 별도 권리 검토 |
| 개인 환경 정보 | 개인 PC 절대 경로, 에디터 설정, 세션 작업 일지 |

기존 장문 README와 내부 구현 일지는 삭제하지 않고 Git 제외 `private/archive/`로 보관했습니다. 공개에 필요한 정보만 현재 문서에 정리했습니다. 상위 작업 폴더의 소개 사이트·프로토타입·디자인·연구자료는 이 저장소로 옮기지 않습니다.

## 공개 전 체크리스트

- [ ] `python scripts/check_repository.py`: 후보 경로, 문서 링크, 개인 경로·키 패턴 확인
- [ ] `python scripts/check_secrets.py`: 로컬 `.env`의 실제 비밀값과 비교
- [ ] `git status --short --untracked-files=all`: 공개 후보 직접 검토
- [ ] `git status --short --ignored`: 제외 대상 확인
- [ ] 소스·주석·스크린샷·Git diff에서 개인정보와 권리 문제 점검
- [ ] 테스트·빌드 실행 결과와 알려진 제약 확인
- [ ] MIT 라이선스 고지 및 제3자 리소스의 별도 조건 확인
- [ ] 원격 URL과 브랜치 확인 후 승인된 범위만 커밋·푸시

공개 시 무조건 `git add .` 하기보다 허용 경로별로 추가하고 `git diff --cached --stat`, `git diff --cached --check`, `git diff --cached`를 확인하는 방식을 권장합니다. 커밋·푸시는 저장소 소유자가 승인한 범위에 한해 수행합니다.

자동 검사는 Git에 이미 추적된 금지 경로도 검사하지만 검사 내용은 현재 작업 파일 기준이며 staging된 이전 내용이나 Git 이력 전체를 읽지 않습니다. 문서 링크는 인라인 링크의 로컬 파일 대상만 확인하며 앵커·외부 URL은 검증하지 않습니다. 이미지 속 개인정보·모든 형태의 비밀값을 검사하지는 못하므로 실제 공개 직전 수동 검토를 대체하지 않습니다.
